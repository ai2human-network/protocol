# AI2Human Improvement Proposals

AIPs govern changes to public protocol semantics.

## Process

1. Copy `AIP-template.md` to `AIP-NNNN-title.md`.
2. Open a pull request with status `Draft`.
3. Document compatibility, security, privacy, funding, and settlement impact.
4. Collect implementation feedback.
5. A maintainer changes status to `Accepted`, `Rejected`, or `Withdrawn`.
6. Accepted proposals land with schema/spec updates and migration guidance.

Numbers are assigned by maintainers. A merged AIP is an architectural record, not proof that every implementation has shipped it.
